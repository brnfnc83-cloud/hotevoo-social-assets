# HOTEVOO® social assets

Public media files for scheduled HOTEVOO® social posts (Instagram via Metricool).
Files are served from `raw.githubusercontent.com` so the scheduler can fetch them.

`nov2026/<date>_<content-id>/`: slides (JPEG 1080×1350) or Reel (MP4 1080×1920 + cover.jpg).
